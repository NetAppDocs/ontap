= Modify destination volume capacity in an ONTAP SVM DR relationship 
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Beginning with ONTAP 9.20.1, storage administrators and data protection administrators can adjust some volume capacity attributes on an SVM DR destination volume to keep destination autosize limits aligned with source growth, to increase snapshot reserve for the destination's retention, and service provider administrators can manage multi-tenant DR customers accurately based on destination capacity.

.Steps

== Adjust the maximum size SVM DR destination volumes can grow automatically

. To modify the volume’s maximum autosize value, enter the following command:
+
`volume modify -vserver <dest svm name> -volume <vol name> -max-autosize <integer>`
+
Example:
+
----
volume modify -vserver svmdr_dst -volume vol1 -max-autosize 10TB
----

== Adjust the minimum size SVM DR volumes can shrink automatically

. To modify a volume’s minimum autosize value, enter the following command:
+
`volume modify -vserver <dest svm name> -volume vol1 -min-autosize <integer>`
+
Example:
+
----
volume modify -vserver svmdr_dst -volume vol1 -min-autosize 1TB
----

== Change the volume’s autosize mode

. To change the autosize mode, enter the following command:
+
`volume modify -vserver svmdr_dst -volume vol1 -autosize-mode`
+
Example:
+
----
volume modify -vserver svmdr_dst -volume vol1 -autosize-mode grow
----

== Adjust the amount of space reserved for snapshots

. To change the percentage of space reserved for snapshots, enter the following command:
+
`volume modify -vserver <dest svm name> -volume <vol name> -percent-snapshot-space <integer>`
+
Example:
+
----
volume modify -vserver svmdr_dst -volume vol1 -percent-snapshot-space 25
----
