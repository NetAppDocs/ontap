= Calculate reclaimable space before deleting snapshots
:icons: font
:imagesdir: ../media/

[.lead]
You can select snapshots you want to delete and calculate the reclaimable space before you delete them. 

In releases earlier than ONTAP 9.20.1, calculating reclaimable space is supported on FlexVol volumes, and for FlexGroup volumes, it requires you to manually combine snapshot usage across FlexGroup constituent volumes. Beginning with ONTAP 9.20.1, you can calculate reclaimable space for snapshots in FlexGroup volumes. 


.Steps
You can perform this task from System Manager or the ONTAP CLI.

[role="tabbed-block"]
====
.System Manager
--

. Click *Storage > Volumes*.
. Select the volume from which you want to delete snapshots.
. Click *Snapshots*.
. Select one or more snapshots.
. Click *Calculate Reclaimable Space*.
--

.CLI
--
. Calculate reclaimable space:
+
`volume snapshot compute-reclaimable -vserver <svm_name> -volume <volume_name> -snapshots <snap1,snap2,snap3>`

--
====
