= Configure ONTAP user password expiry alerts in System Manager
:icons: font
:imagesdir: ../media/

[.lead]
Beginning with ONTAP 9.20.1, if the role associated with a user account is configured for password expiry alerts, the user receives a top-of-page banner alert in System Manager immediately after logging in, beginning 14 days before the password expires. The alert is updated each time the user logs in to show the number of days remaining until the password expires. You can configure expiry alerts when you add or edit an administrator role.

.Steps

. Select *Cluster > Settings*.
. Select image:arrow.gif[arrow icon] next to *Users and roles*.
. Configure password expiry alerts when adding or editing a user role.
+
* To configure when adding a user role, select image:icon_add.gif[add icon] under *Roles*. Enter a name for the role, and then select the password expiration period and a password expiration alert.
* To configure when editing a user role, select the user role under *Roles*, select *Edit*, and then select the password expiration period.
* Select *Add*.

.Result
The user receives a top-of-page banner alert in System Manager immediately after logging in, beginning the selected number of days before the password expires. The alert updates each time the user logs in to show the number of days remaining until the password expires.
