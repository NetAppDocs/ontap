= View cluster information from the ONTAP System Manager dashboard
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The System Manager dashboard offers a quick and comprehensive view of your ONTAP cluster from a single location.

From the System Manager dashboard, you can view information about your cluster health, capacity, network, and performance, including important alerts, the efficiency and capacity of storage tiers and volumes, the status and availability of cluster nodes, the most active applications and objects, and performance metrics.

Beginning with ONTAP 9.19.1, SVM administrators can monitor and manage their own SVMs using a dedicated SVM administrator dashboard in ONTAP System Manager. For more information, see link:task-svm-admin-dashboard-sm.html[Manage and monitor SVMs with System Manager]. 

The dashboard includes four panels described as follows:

== View the cluster health

In the *Health* section of the  ONTAP System Manager dashboard, you can view general information about your cluster such as its name, ONTAP version, and date of creation.  You can also view the overall health of your cluster nodes, cluster-level errors, warnings, alerts, and suggested modifications to enhance cluster performance.

Beginning with ONTAP 9.20.1, a health alert is displayed 30 days before a cluster or storage virtual machine (SVM) certificate expires. The alert is updated daily to show the number of days remaining until expiration. You can modify the default 30-day alert threshold to any number of days from 0 to 90, disable it so that no alerts are displayed, or suppress alerts for already expired certificates while continuing to receive alerts for upcoming expirations.  

* To view cluster health information, select image:icon_arrow.gif[Arrow icon] next to *Health* on the dashboard. 
* To modify certificate expiry setting, select the alert, and then select *Certificate Settings*. 

== View the cluster capacity

In the *Capacity* section of the  ONTAP System Manager dashboard, you can view the storage space of a cluster. You can view the total logical space used, total physical space used, and the available disk space. 

You can choose to register with ActiveIQ to view historical cluster data.

Select image:icon_arrow.gif[Arrow icon] next to *Capacity* on the dashboard to view cluster capacity information including an overview of the tiers associated with a cluster such as the total space, used space, and available space. Details are also displayed for throughput, IOPS, and latency. link:./concepts/capacity-measurements.html[Learn how ONTAP reports used storage]. 

You can choose to add a local tier or a cloud tier using the Capacity view. For more information, refer to link:task_admin_monitor_capacity_in_sm.html[View the capacity of a cluster].

== View the cluster network

In the *Network* section of the  ONTAP System Manager dashboard, you can view the physical ports, network interfaces, and storage VMs that are part of the network. 

The Network view displays the type of clients connected to the network. Each of these network-connected clients are represented by a number (for example "NVMe/FC 16"). Select the number to view specific details on each of these network elements.

Select image:icon_arrow.gif[Arrow icon] next to *Network* on the dashboard to view an expansive, full-page view of the network that encompasses ports, network interfaces, storage VMs, and hosts on the network.

== View the cluster performance
 
In the *Performance* section of the  ONTAP System Manager dashboard, you can view performance statistics to help to monitor the health and efficiency of your ONTAP cluster. The statistics include key cluster performance indicators such as latency, throughput, and IOPS, represented as graphs. 

The Performance view displays performance statistics at different time intervals by day, hour, week, or year. You can quickly analyze cluster performance by using the various graphs and identify the characteristics that might require optimization. This quick analysis helps you decide how you might add or move workloads. You can also look at peak usage times to plan for potential changes.

The performance view displays the total performance metrics related to latency, throughput, and IOPS.

Beginning with 9.15.1, the performance view is enhanced to display graphs for read, write, other, and total performance metrics related to latency, throughput, and IOPS. Other metrics include any operations that aren't read or write.

The performance values refresh every 3 seconds and the performance graph refreshes every 15 seconds. A graph will not display if information about cluster performance is not available.

Select image:icon-expansion-arrows.png[Expansion icon] next to *Performance* on the dashboard to see a full-page view of the performance metrics by hour, day, week, month, and year. You can also download a report of the performance metrics in your local system.
