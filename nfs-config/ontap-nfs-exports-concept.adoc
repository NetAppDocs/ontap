= Learn about ONTAP NFS exports
:icons: font
:imagesdir: ../media/

[.lead]
ONTAP controls NFS client access through export policies assigned to volumes or qtrees. Each policy contains rules that define which clients can access data and the permissions they receive.

== Export policies and rules

An SVM can contain multiple export policies. Each policy contains one or more export rules that specify client matches and access permissions. You can apply an export policy to more than one volume.

== Apply export policies to volumes and qtrees

Assign an export policy to a volume or qtree to control NFS client access to that storage. A policy assigned to a volume applies to the volume's data; you can assign a policy directly to a qtree when you need to control access to that qtree.

== Volume junction paths

Volumes are mounted in the SVM namespace at a junction path. NFS clients use this path to access the volume's data. The junction path can differ from the volume name.
