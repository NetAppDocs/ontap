== NAS

[cols="30%,70%",options="header"]
|===
| Update | Description
a|
xref:../smb-admin/supported-versions-functionality-concept.adoc[SMB normalized name query support for Windows clients]
a|
Windows clients can retrieve canonical file and directory names in a single request, reducing file-open latency and improving SMB compatibility for enterprise desktops, applications, and file servers. ONTAP automatically returns canonical paths for open files and directories, avoiding per-component lookups on Windows 11 24H2 and later clients without additional configuration.

//ONTAPDOC-4115
//Deena
|===

== SAN

[cols="30%,70%",options="header"]
|===
| Update | Description
a|
SAN copy offload performance improvements
a|
SAN copy offload performance improves for eligible SCSI extended copy (FCP and iSCSI) and NVMe copy (NVMe/FC and NVMe/TCP) workloads. This enhancement helps large storage-side copy operations complete faster in supported SAN environments.
// ONTAPDOC-3977
// Deena
a|
Increased SCSI persistent reservation registration scale
a|
The maximum supported number of SCSI-3 persistent reservation registrations per LUN increases from 182 to 256. This helps larger clustered SAN environments, such as VMware guest clustering and Windows Server Failover Clustering, support more host registrations on shared LUNs without changing persistent reservation administration workflows.

//ONTAPDOC-4110
// Deena
|===

== Object Storage

[cols="30%,70%",options="header"]
|===
| Update | Description
a|
S3 flexible checksum support
a|
ONTAP S3 supports flexible checksums using the CRC-64NVME (Cyclic Redundancy Check 64-bit for NVMe) algorithm for S3 NAS buckets. ONTAP validates, stores, and returns checksums when clients include checksum headers in requests, enabling verification of data integrity across PUT, GET, and multipart upload operations.

// ONTAPEX-217182
// Deena
a|
Flexible S3 bucket sizing
a|
ONTAP S3 supports a configurable default size for new buckets. When configured, buckets created without an explicit size through the ONTAP CLI, REST API, or S3 API use the configured default instead of the platform minimum.

// ONTAPEX-217962
// Deena
|===

File System Analytics scans and System Manager File System Explorer browsing preserve directory access-time (`atime`) metadata. This helps maintain accurate `atime` values for archival, tiering, compliance, and data lifecycle workflows.
