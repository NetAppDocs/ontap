== Storage resource management enhancements

[cols="30%,70%",options="header"]
|===
| Update | Description
a|
xref:../task_nas_file_system_analytics_view.adoc[File System Analytics access-time preservation]
a|
Beginning with ONTAP 9.20.1, File System Analytics scans and System Manager File System Explorer browsing preserve file and directory access-time (`atime`) metadata instead of updating it. This keeps `atime` values accurate for archival, tiering, compliance, and data lifecycle workflows that depend on reliable access-time information.

// ONTAPEX-216558
|===
