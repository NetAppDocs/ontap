= Manage ARP/AI automatic enablement during upgrades
:toclevels: 1
:imagesdir: ../media/

[.lead]
When upgrading to ONTAP 9.18.1 or later, Autonomous Ransomware Protection with AI (ARP/AI) is automatically enabled by default on all new volumes for AFF A-series, AFF C-series, ASA, and ASA r2 systems after a 12-hour grace period, provided an ARP license is installed. Use this procedure to opt out of automatic default enablement during or after the grace period, or to change the setting at any time after the upgrade.

NOTE: If you are running ONTAP 9.15.1 or earlier, see link:index.html[Learn about Autonomous Ransomware Protection].

NOTE: If you are running ONTAP 9.17.1 or earlier, automatic cluster-level default enablement does not apply. You can configure SVM-level default enablement using link:enable-default-arpai.html[Enable ARP/AI by default in new volumes].

NOTE: Existing volumes must be link:enable-arpai.html[manually enabled] for ARP/AI.

NOTE: Beginning with ONTAP 9.19.1, default ARP enablement applies to clusters that include SnapMirror synchronous and SnapMirror active sync SAN relationships. In ONTAP 9.18.1, default enablement was suppressed for these configurations. For cross-cluster SnapMirror synchronous relationships, default enablement activates after both the source and destination clusters are upgraded to ONTAP 9.19.1.

.About this task

The setting you choose can be changed later. After the grace period, you always have the flexibility to turn automatic default enablement on or off at any time:

[source,cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false|true
----

.Steps

You can use System Manager or the ONTAP CLI to manage ARP/AI automatic default enablement.

[role="tabbed-block"]
====
.System Manager
--
. Select *Cluster > Settings*.
. Do one of the following:
* Disable during active grace period:
+
.. In the *Anti-ransomware* section, you'll see a message indicating the hours remaining before ARP/AI will be enabled. Select *Don't enable*.
.. Select *Disable* in the next dialog box to confirm that default ARP/AI enablement is turned off for new volumes.

* Disable after grace period:
+
.. In the *Anti-ransomware* section, select image:icon_pencil.gif[Edit icon].
.. Select the checkbox and then *Save* to disable automatic default ARP/AI enablement for new volumes.
--

.CLI
--
. Check the automatic enablement status:
+
[source,cli]
----
security anti-ransomware auto-enable show
----
. Disable automatic default enablement for new volumes:
+
[source,cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false
----
--
====
