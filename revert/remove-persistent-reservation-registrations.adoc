= Remove persistent reservation registrations before reverting from ONTAP 9.20.1
:icons: font
:imagesdir: ../media/

[.lead]
Beginning with ONTAP 9.20.1, ONTAP supports up to 256 SCSI-3 persistent reservation registrations per LUN, increased from 182. If any LUN has historically exceeded 182 registrations, ONTAP blocks reversion to earlier ONTAP versions, regardless of the current registration count. Before you revert, check all LUNs and remove any persistent reservation registrations.
