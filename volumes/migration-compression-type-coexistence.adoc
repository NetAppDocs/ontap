= Support for compression type coexistence during ONTAP volume migration
:icons: font
:imagesdir: ../media/

[.lead]
[.lead]
When a volume is migrated between ONTAP systems, the source volume might use a different data compression type than the destination volume.

Supported compression types include secondary, adaptive 8K, and temperature-sensitive storage (TSSE). During migration, these compression types can temporarily coexist on the destination volume as follows:

[options="header", cols="4"]
|===
|Source volume|Destination volume |Coexistence supported for migration|Application I/O read/write size on destination volume

|Secondary compression type |TSSE/32k inline compression type|Yes|Auto
|Adaptive 8k compression type|TSSE/32k inline compression type|Yes|Auto
|Secondary compression type |Adaptive 8k compression type|No|Not supported
|===

After the compression type is changed from secondary or adaptive 8K compression to TSSE/32k inline compression, the *compression type* displayed in the `volume efficiency show` command output does not change even after all existing blocks have been converted. The compression type remains *secondary* for a converted secondary volume and *adaptive* for a converted adaptive 8K volume.

New data written to volumes converted from secondary or adaptive 8K compression is compressed with TSSE.

Learn to link:move-between-secondary-adaptive-compression-task.html[move between secondary and adaptive compression].
