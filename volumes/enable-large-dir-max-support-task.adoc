= Enable ONTAP support for large directory maximum size
:icons: font
:imagesdir: ../media/

[.lead]
Beginning with ONTAP 9.20.1, you can enable and configure support for a larger maximum directory size either when creating a volume or modifying an existing volume. This allows directories to contain up to approximately 25 million files, folders, and other entries based on a maximum 4GB directory size.

[CAUTION]
====
After increasing the maximum directory size, you cannot reduce it without recreating the affected directory or directories on the volume.
====

.Before you begin

Before creating or modifying a volume to support a larger maximum directory size, make sure you are a cluster or SVM administrator.

== Create a new volume

You can set a larger maximum directory size when creating a new volume.

.Steps

. Create a volume with support for the larger directory maximum size enabled:
+
[source,cli]
----
volume create -vserver <svm_name> -volume <volume_name> -aggregate <aggr_name> -is-dir-index-transfer-enabled true
----
+
.Example
+
----
volume create -vserver vs1 -volume big_dir1 -aggregate aggr1 -is-dir-index-transfer-enabled true
----

. Increase the maximum directory size, up to 4 GB:
+
[source,cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.Example
+
----
volume modify -vserver vs1 -volume big_dir1 -maxdir-size 4GB
----

== Modify an existing volume

You can set a larger maximum directory size by modifying an existing volume.

.Steps

. Enable support for the larger directory maximum size on an existing volume:
+
[source,cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -is-dir-index-transfer-enabled true
----
+
.Example
+
----
volume modify -vserver vs2 -volume data_vol -is-dir-index-transfer-enabled true
----

. Increase the maximum directory size up to 4 GB:
+
[source,cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.Example
+
----
volume modify -vserver vs2 -volume data_vol -maxdir-size 4GB
----
