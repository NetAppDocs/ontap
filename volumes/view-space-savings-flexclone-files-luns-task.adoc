= View ONTAP space savings with FlexClone files and FlexClone LUNs
:icons: font
:imagesdir: ../media/

[.lead]
You can view the percentage of disk space saved by block sharing on a volume containing FlexClone files and FlexClone LUNs. You might do this as part of capacity planning.

.Steps

. View the space saving achieved due to FlexClone files and FlexClone LUNs:
+
[source,cli]
----
volume show -volume <vol_name> -vserver <SVM> -fields used, sis-space-saved, dedupe-space-saved, compression-space-saved
----
+
[NOTE]
====
If you run this command on a deduplication-enabled FlexVol volume, you can view the space saved by both deduplication and FlexClone files and LUNs.
====
